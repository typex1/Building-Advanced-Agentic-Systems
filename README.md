# Building Advanced Agentic Systems

Additional class content.

## 🚀 Quick Start

```bash
git clone https://github.com/typex1/Building-Advanced-Agentic-Systems.git
cd Building-Advanced-Agentic-Systems

# Install uv (needed to run MCP servers via uvx):
curl -LsSf https://astral.sh/uv/install.sh | sh

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Install Kiro
curl -fsSL https://cli.kiro.dev/install | bash

# Log into your Kiro account:
kiro-cli login --use-device-flow
```
